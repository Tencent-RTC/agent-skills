# TRTC Voice AI — Project

A working voice AI agent: React frontend + Fastify backend, powered by TRTC Conversational AI.

Users speak into their browser microphone — the AI listens, thinks, and speaks back in real time. The demo includes live subtitles, AI status indicators (listening / thinking / speaking), and latency metrics. You can switch LLM, STT, or TTS providers without changing integration code.

This project was generated by the [TRTC Voice AI Starter Kit](https://github.com/Tencent-RTC/agent-skills) skill. To continue with AI-guided setup or extend capabilities, open this project in Claude Code, Cursor, or CodeBuddy.

## Run

```bash
pnpm install
pnpm verify        # verify all three keys
pnpm start         # starts web (localhost:5173) + server (localhost:3000)
```

Open http://localhost:5173 and click the mic button.

To stop: `lsof -ti :3000 -sTCP:LISTEN | xargs kill && lsof -ti :5173 -sTCP:LISTEN | xargs kill`

## Architecture

```
web/        React + Vite frontend
            ├── enters TRTC room via trtc-sdk-v5
            ├── calls backend for UserSig and agent control
            └── receives real-time subtitles/status via TRTC custom messages (cmdID=1)

server/     Fastify backend
            ├── GET  /userSig              compute room-entry token (never in browser)
            ├── POST /agent/start          StartAIConversation
            ├── POST /agent/stop           StopAIConversation
            ├── POST /agent/control        interrupt / push text to bot
            ├── POST /agent/update         update prompt or context at runtime
            ├── POST /transcription/start  bilingual subtitles (StartAITranscription)
            ├── POST /transcription/stop
            └── POST /webhook/agent-events receive server-side events (signed)
```

## Switch providers

Tell your IDE's AI assistant what you want to switch, or run:

```bash
pnpm switch-provider --category tts --to minimax
pnpm switch-provider --category llm --to openai
pnpm switch-provider --category stt --to azure
```

The script updates `.env` and the bot restarts automatically.

Supported providers — see full list in `.env.example`.
