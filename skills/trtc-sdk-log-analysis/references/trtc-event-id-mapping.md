# TRTC 事件 ID 映射表（监控/上报数据排障字典）

> 当监控仪表盘、`DescribeUserEvent` / `DescribeUnusualEvent` 接口返回原始事件 ID 时，用本表反查含义。
> 这些事件 ID 是 SDK 上报到后台的结构化事件，与本地日志互为印证。

## 5 张映射表速查

1. **SDK 事件**（1xxx~7xxx）— 终端 SDK 上报的设备/房间/媒体事件
2. **WebRTC 事件**（32xxx~36xxx）— Web SDK 专用
3. **异常体验事件**（1~5）— 用户主观异常（`DescribeUnusualEvent` 的 `ExperienceId`）
4. **房间结束异常事件**（1001~1032）— 房间结束时才上报
5. **实时异常事件**（2001~2026）— 实时监控上报（可能有 5 分钟内延迟）

## 客户报障常用事件组合

### 进房失败排障

- `5001`（开始进入房间）有没有 → 没有 = SDK 没调 enterRoom
- `5002` 第一参数 = 0 → IP 地址信息获取失败 → 网络/DNS 问题
- `5003` 第一参数 = 0 → 进房失败 → 看房间结束异常事件 1xxx
- `5005` 出现 → 服务器连接超时 → **防火墙 UDP 被拦**是首要嫌疑
- 房间结束后查 `1006` + 1009~1012 定位到具体参数错

### 卡顿排障（先分上下行）

| 看到 | 含义 |
|------|------|
| 2003 + 2004 + 2005 | **上行**网络问题（主播侧） |
| 2013 + 2014 + 2015 | **下行**网络问题（观众侧） |
| 2007 / 2017 | 大画面丢包；2008 / 2018 小画面丢包 |
| 2020~2022 | 渲染 fps 异常（设备性能不足，低端机常见） |

### 黑屏 / 无声排障

| 看到 | 排查 |
|------|------|
| 4002 | 摄像头打开失败 → 看 1015~1018（驱动/权限/参数/占用） |
| 2002 第一参数 = 5 / 4 | 摄像头 / 麦克风权限被拒 |
| 2006 | 音频采集音量 0 → 麦克风静音/占用 |
| 2016 | 音频播放音量 0 → 听筒/扬声器路由/远端流异常 |
| 2003 第一参数 = 5 | 性能不足导致 Video 采集中断（低端机） |

### 网络切换 / 音频路由

| 看到 | 含义 |
|------|------|
| 1003 | 网络类型变化（关注 4G ↔ Wi-Fi 切换导致重连） |
| 1001 / 1002 | 有线/蓝牙耳机插拔 |
| 3004 | 扬声器/听筒切换 |
| 7000 第一参数 = 1 | **重进房**（断线重连成功一次） |
| 7001 第一参数 = 1 | **超时退房 = 30 min 未重连成功** → 关联 -3301 |
