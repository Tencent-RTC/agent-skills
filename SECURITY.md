# Security Policy

Tencent RTC takes the security of the TRTC Agent Skills project seriously. This document explains which versions are supported and how to report a vulnerability responsibly.

## Supported Versions

Security updates are provided for the latest published version of the npm package `@tencent-rtc/trtc-agent-skills`.

| Version | Supported |
| ------- | --------- |
| 1.1.x   | Yes       |
| < 1.1   | No        |

We recommend always using the latest release, installed via:

```bash
npx -y @tencent-rtc/trtc-agent-skills@latest add
```

## Reporting a Vulnerability

Please **do not** disclose suspected vulnerabilities in public issues, discussions, or pull requests.

Report security issues privately through **GitHub Security Advisories**:

- Open https://github.com/Tencent-RTC/agent-skills/security/advisories/new
- This creates a private report visible only to the maintainers.

Please include, if possible:

- A description of the issue and its potential impact
- Steps to reproduce or a proof of concept
- Affected version(s)
- Any suggested mitigation

## Response Process

1. We will acknowledge your report within **5 business days**.
2. We will investigate and, where applicable, prepare a fix and coordinate disclosure with you.
3. Once a fix is released, we will credit the reporter (unless anonymity is requested) and publish an advisory.

Thank you for helping keep the TRTC Agent Skills ecosystem safe.
